# Инструкция по переносу данных из Excel в Google Таблицы

Данная инструкция поможет вам перенести данные из Excel файла `Горнодобывающий_комплекс_шаблон.xlsx` в Google Таблицы для интеграции с мобильным приложением мониторинга горнодобывающего комплекса.

## Шаг 1: Подготовка Google Таблицы

1. Откройте [Google Таблицы](https://docs.google.com/spreadsheets) и войдите в свой аккаунт Google.

2. Создайте новую таблицу, нажав кнопку `+ Новая таблица`.

3. Назовите таблицу "Горнодобывающий комплекс" (щелкните по "Новая таблица" вверху и введите название).

## Шаг 2: Импорт данных из Excel

### Метод 1: Загрузка Excel-файла целиком

1. В Google Таблицах нажмите на `Файл` -> `Импортировать`.

2. Выберите вкладку `Загрузить` и перетащите файл `Горнодобывающий_комплекс_шаблон.xlsx` или нажмите `Выбрать файл с устройства`.

3. В диалоговом окне импорта выберите:
   - `Создать новую таблицу` или `Заменить текущий лист` (если у вас пустая таблица)
   - Отметьте `Импортировать все листы`
   - Включите опцию `Да` для `Преобразовать формулы`

4. Нажмите `Импортировать данные`.

### Метод 2: Копирование и вставка листов по отдельности

Если вы хотите больше контроля над процессом импорта, можно копировать данные из Excel и вставлять их в Google Таблицы:

1. Откройте Excel-файл `Горнодобывающий_комплекс_шаблон.xlsx` на вашем компьютере.

2. Выделите все данные на листе "Запасы" (включая заголовки) и скопируйте (Ctrl+C).

3. Вернитесь в Google Таблицы, щелкните по ячейке A1 и вставьте данные (Ctrl+V).

4. Переименуйте лист в "Запасы" (щелкните правой кнопкой мыши по вкладке листа и выберите "Переименовать").

5. Повторите процесс для всех остальных листов: "Заказы", "Очередь грузовиков", "Статистика системы", "Инструкция" и "Продукты".

## Шаг 3: Настройка формул в Google Таблицах

После импорта некоторые формулы могут потребовать коррекции в Google Таблицах:

### Лист "Запасы"

1. Убедитесь, что формулы процента заполнения работают корректно:
   - Формула в ячейке E2 должна быть: `=C2/D2*100 & "%"`
   - Аналогично для всех остальных строк

2. Для автоматического обновления времени в столбце F используйте формулу: `=NOW()`

### Лист "Очередь грузовиков"

1. Проверьте формулу расчета времени завершения загрузки:
   - Формула в ячейке I3 должна быть: `=H3+TIME(0;F3*0.2/60;0)`
   - Обратите внимание, что в Google Таблицах разделителем аргументов является точка с запятой (;), а не запятая (,)

### Лист "Статистика системы"

1. Убедитесь, что ссылки на другие листы работают корректно:
   - Формула для грузовиков в очереди: `=COUNTIF('Очередь грузовиков'!E:E;"Ожидание")`
   - Формула для грузовиков на загрузке: `=COUNTIF('Очередь грузовиков'!E:E;"Загрузка")`
   - Формула для среднего времени ожидания: `=AVERAGE('Очередь грузовиков'!H:H-'Очередь грузовиков'!D:D)*1440`
   - Формула для дневной производительности: `=SUM('Очередь грузовиков'!F:F)`

2. Для последнего обновления используйте: `=NOW()`

## Шаг 4: Настройка доступа к Google Таблице

Для интеграции с приложением и совместной работы необходимо настроить доступ:

1. Нажмите кнопку `Поделиться` в правом верхнем углу.

2. Для доступа через приложение:
   - Скопируйте ID таблицы из URL. URL имеет вид: `https://docs.google.com/spreadsheets/d/YOUR_SPREADSHEET_ID/edit`
   - ID таблицы - это длинная строка символов между `/d/` и `/edit`
   - Сохраните этот ID, он понадобится для настройки приложения
   - Предоставьте доступ сервисному аккаунту (email сервисного аккаунта предоставляется администратором приложения) с правами "Редактор"

3. Для совместной работы с коллегами:
   - В диалоге "Поделиться" введите email-адреса коллег
   - Выберите права доступа ("Редактор", "Комментатор" или "Читатель")
   - По желанию, добавьте сообщение и отправьте приглашения

## Шаг 5: Регулярное обновление данных

Для эффективной работы с приложением важно регулярно обновлять данные в таблице:

1. **Обновление запасов:**
   - Ежедневно или по мере изменения уровня запасов обновляйте значения в столбце "Текущее количество" на листе "Запасы"
   - Процент заполнения и время обновления будут рассчитаны автоматически

2. **Управление заказами:**
   - Добавляйте новые заказы на лист "Заказы" (вручную или через приложение)
   - Обновляйте статус заказов по мере обработки

3. **Управление очередью грузовиков:**
   - Добавляйте новые грузовики при их прибытии
   - Обновляйте статус грузовиков ("Ожидание" → "Загрузка" → "Завершено")
   - Указывайте время начала загрузки в столбце "Время загрузки"

4. **Обновление статуса системы:**
   - Обновляйте "Статус системы" и "Температуру системы" на листе "Статистика системы"
   - Остальные значения будут обновляться автоматически

## Дополнительные функции Google Таблиц

### Настройка уведомлений

1. Нажмите `Инструменты` -> `Настройка уведомлений`.

2. Выберите, когда хотите получать уведомления (например, "При любых изменениях").

3. Настройте доставку уведомлений (на email или через мобильное приложение Google Таблицы).

### Создание графиков

Вы можете создать графики для визуализации данных:

1. Выделите данные для графика (например, название и текущее количество материалов).

2. Нажмите `Вставка` -> `Диаграмма`.

3. Настройте тип и параметры диаграммы.

4. Разместите диаграмму на соответствующем листе или создайте отдельный лист для диаграмм.

### Автоматизация с Google Apps Script

Для продвинутых функций можно использовать Google Apps Script:

1. Нажмите `Расширения` -> `Apps Script`.

2. Создайте скрипт, например, для автоматического уведомления о низком уровне запасов:

```javascript
function checkInventoryLevels() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("Запасы");
  var data = sheet.getDataRange().getValues();
  
  for (var i = 1; i < data.length; i++) {
    var currentAmount = data[i][2]; // Столбец C - Текущее количество
    var capacity = data[i][3];      // Столбец D - Вместимость
    var percentage = currentAmount / capacity;
    
    if (percentage < 0.2) {
      // Отправка уведомления по email
      MailApp.sendEmail({
        to: "your-email@example.com",
        subject: "Низкий уровень запасов: " + data[i][1], // Название материала
        body: "Текущий уровень: " + currentAmount + " из " + capacity + " (" + (percentage * 100).toFixed(1) + "%)"
      });
    }
  }
}
```

3. Настройте триггер для запуска скрипта по расписанию:
   - Нажмите `Триггеры` в левой панели Apps Script
   - Нажмите `Добавить триггер`
   - Выберите функцию, источник события (по времени), тип события (например, ежедневно) и время
