# Пример настройки Google Таблиц для приложения мониторинга горнодобывающего комплекса

В данном документе представлен пример структуры Google Таблиц для интеграции с приложением мониторинга горнодобывающего комплекса. Интеграция с Google Таблицами позволяет операторам комплекса вводить данные напрямую в таблицы, а приложение будет автоматически обновляться, отображая эти данные.

```

```

### Лист 4: Статистика системы (System Stats)

Этот лист содержит общую статистику и данные о системе.

| Параметр | Значение | Формула/Расчет |
|----------|----------|--------------------|
| Статус системы | Работает | Обновляется вручную |
| Грузовиков в очереди | =COUNTIF(Queue!D:D,"Ожидание") | Подсчет грузовиков со статусом "Ожидание" |
| Грузовиков на загрузке | =COUNTIF(Queue!D:D,"Загрузка") | Подсчет грузовиков со статусом "Загрузка" |
| Среднее время ожидания (мин) | =AVERAGE(Queue!G:G-Queue!D:D)*1440 | Среднее время между прибытием и началом загрузки в минутах |
| Дневная производительность (тонн) | =SUM(Queue!E:E) | Общее количество отгруженного материала |
| Температура системы (°C) | 32.5 | Обновляется вручную или через сенсоры |
| Последнее обновление | =NOW() | Текущая дата и время |

#### Формула для подсчета грузовиков в очереди:
```
=COUNTIF(Queue!D:D,"Ожидание")
```
Эта формула подсчитывает количество строк в столбце D на листе Queue, где значение равно "Ожидание".

#### Формула для среднего времени ожидания:
```
=AVERAGE(Queue!G:G-Queue!D:D)*1440
```
Эта формула вычисляет среднюю разницу между временем начала загрузки и временем прибытия и конвертирует результат в минуты.

## Интеграция с приложением

Для интеграции Google Таблиц с приложением необходимо выполнить следующие шаги:

1. **Создать проект в Google Cloud Console:**
   - Перейдите на [console.cloud.google.com](https://console.cloud.google.com)
   - Создайте новый проект
   - Активируйте Google Sheets API и Google Drive API

2. **Создать сервисный аккаунт:**
   - В разделе "IAM и администрирование" создайте сервисный аккаунт
   - Загрузите ключ JSON для сервисного аккаунта
   - Сохраните ключ в безопасном месте

3. **Создать Google Таблицу:**
   - Создайте новую таблицу в Google Sheets
   - Создайте необходимые листы (Запасы, Заказы, Очередь грузовиков, Статистика системы)
   - Установите заголовки и формулы, как описано выше
   - Предоставьте доступ к таблице сервисному аккаунту (роль "Редактор")

4. **Настроить переменные окружения в приложении:**
   - Добавьте следующие переменные в файл `.env` или настройте их в среде размещения приложения:
   ```
   GOOGLE_SHEETS_ID=ваш-идентификатор-таблицы
   GOOGLE_SERVICE_ACCOUNT_EMAIL=email-сервисного-аккаунта@project-id.iam.gserviceaccount.com
   GOOGLE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n"
   ```

После выполнения этих шагов приложение будет автоматически синхронизировать данные с Google Таблицами, предоставляя операторам удобный интерфейс для мониторинга и управления горнодобывающим комплексом.

## Особые замечания

1. **Безопасность данных:**
   - Всегда храните учетные данные сервисного аккаунта в защищенном месте
   - Не включайте приватные ключи в исходный код приложения
   - Регулярно проверяйте и обновляйте разрешения доступа к таблице

2. **Производительность:**
   - Избегайте частых обновлений таблицы, чтобы не превысить квоты API
   - Рассмотрите возможность кэширования данных на стороне приложения
   - Для больших объемов данных рассмотрите использование пакетных операций

3. **Резервное копирование:**
   - Регулярно создавайте резервные копии данных
   - Настройте автоматические экспорты таблицы
   - Храните исторические данные в отдельных листах или таблицах для аналитики
