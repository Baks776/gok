# Приложение для мониторинга горнодобывающего комплекса

Мобильное веб-приложение для отслеживания запасов материалов, управления очередью грузовиков и интеграции с Google Таблицами для удобного управления горнодобывающим комплексом.

![Приложение для мониторинга](./screenshot.png)

## Возможности

- 📊 **Мониторинг запасов** - отслеживание уровня запасов 6 типов щебня и материалов
- 🚚 **Управление очередью грузовиков** - визуализация текущей очереди и статусов погрузки
- 📱 **Доступность на мобильных устройствах** - работает на iOS и Android через браузер
- 📝 **Управление заказами** - создание и отслеживание статусов заказов
- 🔄 **Интеграция с Google Таблицами** - данные могут вводиться операторами через знакомый интерфейс Google Таблиц
- 🗺️ **Отображение местоположения** - страница с картой и контактной информацией
- 🌐 **Многоязычность** - полностью на русском языке

## Технологии

- **Frontend:** React, TypeScript, TailwindCSS, Shadcn UI
- **Backend:** Node.js, Express
- **База данных:** PostgreSQL с Drizzle ORM
- **Интеграции:** Google Sheets API
- **Деплой:** Replit

## Начало работы

### Предварительные требования

Для запуска приложения вам понадобится:

- Node.js (версия 20 или выше)
- PostgreSQL (база данных)
- Учетная запись Google (для интеграции с Google Таблицами)

### Установка

1. **Клонирование репозитория**

```bash
git clone https://github.com/your-username/mining-complex-monitor.git
cd mining-complex-monitor
```

2. **Установка зависимостей**

```bash
npm install
```

3. **Настройка базы данных**

Создайте файл `.env` в корневой директории проекта и добавьте следующую информацию:

```
DATABASE_URL=postgresql://username:password@localhost:5432/mining_complex
```

Замените `username`, `password` и другие значения на ваши учетные данные PostgreSQL.

4. **Инициализация базы данных**

```bash
npm run db:push
npm run db:seed
```

5. **Настройка Google Sheets** (необязательно, но рекомендуется)

Для интеграции с Google Таблицами, следуйте инструкциям в файле [GOOGLE_SHEETS_EXAMPLE.md](./GOOGLE_SHEETS_EXAMPLE.md).

После получения учетных данных API, добавьте их в файл `.env`:

```
GOOGLE_SHEETS_ID=ваш-идентификатор-таблицы
GOOGLE_SERVICE_ACCOUNT_EMAIL=your-service-account@project-id.iam.gserviceaccount.com
GOOGLE_PRIVATE_KEY="-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n"
```

### Запуск приложения

```bash
npm run dev
```

Приложение будет доступно по адресу `http://localhost:5000`.

## Адаптация приложения под ваши нужды

### Изменение текстов и переводов

Все тексты и переводы находятся непосредственно в компонентах React. Для изменения текста:

1. Найдите соответствующий файл в директории `client/src/pages` или `client/src/components`
2. Измените текст в компоненте
3. Для более масштабных изменений рассмотрите возможность использования библиотеки i18n

### Добавление новых типов продукции

Для добавления новых типов материалов:

1. Обновите файл `shared/schema.ts` для изменения схемы базы данных
2. Выполните `npm run db:push` для применения изменений в базе данных
3. Обновите файл `db/seed.ts` для добавления новых данных
4. Выполните `npm run db:seed` для заполнения базы данных

### Изменение дизайна

Приложение использует TailwindCSS и компоненты Shadcn UI:

1. Настройте цвета и темы в файле `client/src/index.css`
2. Для более глубоких изменений отредактируйте `tailwind.config.ts`
3. Компоненты пользовательского интерфейса можно настроить в директории `client/src/components/ui`

## API Endpoints

Приложение предоставляет следующие API endpoints:

- `GET /api/inventory` - получение списка всех запасов
- `GET /api/inventory/:id` - получение информации о конкретном запасе
- `PATCH /api/inventory/:id` - обновление информации о запасе
- `GET /api/products` - получение списка всех продуктов
- `GET /api/products/:id` - получение информации о конкретном продукте
- `GET /api/queue` - получение текущей очереди грузовиков
- `GET /api/queue/stats` - получение статистики очереди
- `POST /api/queue` - добавление грузовика в очередь
- `PATCH /api/queue/:id` - обновление статуса грузовика
- `POST /api/orders` - создание нового заказа
- `GET /api/orders` - получение списка всех заказов
- `PATCH /api/orders/:id` - обновление статуса заказа
- `GET /api/system-status` - получение системного статуса
- `PATCH /api/system-status` - обновление системного статуса
